# 旧版几何缓存

`<p3d/legacy_graphics.hpp>` 的 `decode_legacy_graphics(bytes, profile, limits)` 读取版本号为 3.1 的几何存档。这个格式与 BGFB 不同，不应将两者的读取器混用。

```cpp
#include <p3d/legacy_graphics.hpp>

auto result = p3d::decode_legacy_graphics(bytes);
if (result.at("status") == "parsed") {
    for (const auto& entry : result.at("entries")) {
        const auto& style = entry.at("style");
        const auto& geometry = entry.at("geometry");
        // 按 geometry.kind 读取对应几何，样式保留为独立数据。
    }
}
```

`entries` 按保存顺序提供独立条目及源范围，不合并同内容的条目。每项的 `style` 保留 RGB、线型、线宽、透明度、线型比例、两个宽度和图层编号；容器末尾的 `container_style` 单独保存。读取器不提前执行样式继承、材质覆盖或活动几何选择。所有源偏移相对于传入存档的首字节。

## 支持的数据

- 单个曲线图元、曲线集合及嵌套子集合；图元支持线段、折线、椭圆弧和点串。`boundary_code` 保留原值，不推断闭合或区域用途。
- 多面体的布局头、三维点、二维参数、法线、RGB 因子、整型颜色、颜色表和浮点颜色通道。
- 相互独立的点、参数、法线和颜色索引，保留原始顺序、符号及零分隔值。
- 名称、面索引、面参数范围、保存的源索引和面编号，以及边链的拓扑类型、声明编号数、实际保存编号和边索引。

池和索引通道提供 `count`、`values`、`source_offset` 和 `source_byte_count`，范围包含其计数头。面参数记录的线格式是 176 字节，不能用运行时结构体大小读取。`source_index_stored_uint32` 和 `face_ids_stored_int32` 明确表示实际保存的 32 位字段；写入前更高的位没有保存在这些字段里，库不会补造。

只有已确认的变长索引网格布局提供派生 `polygons`。布局不支持、点索引越界或缺少结束分隔值时，`polygon_derivation_status` 给出原因，源通道仍保留，不自动修复拓扑。存档 `parsed` 与可派生有效多边形是不同的状态。

名称按 MFC CString 的长度及 Unicode 标记读取。Unicode 名称保留 `code_units`，有效时另提供 UTF-8 `text`，包括保存的内嵌零字符。无效代理项通过 `text_status: invalid_utf16` 报告，不替换源代码单元。ANSI 名称仅对 ASCII 子集提供文本，其他字节的代码页由调用方决定；可根据 `data_offset` 和源存档读取原字节。

有限浮点值提供 JSON 数字；非有限值提供包含 `value: null`、`ieee754_hex` 和 `source_offset` 的对象，以保留位模式。完整源存档在 `source_storage` 中。

## 原生读写约定

`LegacyGraphicsProfile::writer_2025` 是默认选项，描述已确认的原生写入布局。`reader_2025` 描述对应原生读取器期望的布局。两者存在不一致，读取失败时不会自动切换。

写入布局的非空浮点颜色项保存一个 float32 红色值和两个来自 RGB 因子通道的 float64 值，因此分别命名为 `red_float32`、`factor_green_float64` 和 `factor_blue_float64`；这两个 double 不能当作原浮点颜色的绿、蓝分量。读取布局则是三个 float32 分量。

边链写入布局先存声明的拓扑编号数 N，却按后置的边索引数 M 写入 M 个拓扑编号，再存 M 和 M 个边索引。N 与 M 可能不同。默认读取器枚举满足后置计数和整个存档边界的解释；不会根据编号看起来是否合理选一个结果。读取布局则按 N 个编号、M 个索引直接读取。

`native_reader_wire_compatible: false` 表示该网格存在上述已识别的读写布局差异；它不是对其他运行时行为或所有软件版本的兼容性保证。缺失的源颜色分量或未写入的编号无法从这些字段恢复。

## 状态与预算

- `parsed`：受支持布局有唯一的完整存档解释，且搜索已完成。直接读取 `entries` 和 `container_style`。
- `ambiguous`：已发现多个完整解释。结果位于 `hypotheses`，没有默认选中的 `entries`。同时检查 `candidate_set_complete`，区分候选已穷尽和搜索提前停止。
- `not_parsed`：没有完整解释，或仅发现一个候选但尚未完成搜索。查看 `reason`、`hypotheses` 和 `unsupported_branch_encountered`，不要把单个未确认候选当作成功结果。

`LegacyGraphicsLimits` 限制输入字节、条目数、累计处理值、搜索工作量、曲线嵌套深度、名称长度和保留解释数量。所有尝试共享预算，不因回溯重置。值预算也计入保留结果的复制开销；它不是精确的输出元素计数。超过输入字节上限时不会复制 `source_storage`。未知条目／曲线类型不猜测长度、不跳到下一个条目；搜索中的未知分支也不能据此排除并宣称唯一。

当前不支持其他存档版本、该存档中的 B 样条图元、CSG、实体和文字条目。它们与库中其他格式的同名几何接口不等价，不会套用其他格式继续读取。

属性块 `PBM_BimBase.GraphicsGeom` 使用同一读取器，并在 `decoded.archive` 提供有序存档。只有唯一读取成功才提供 `decoded`；失败或歧义保留原二进制 token，可直接调用本接口查看候选。单条目保留既有的平铺兼容字段，多条目不会生成一个合并的网格。解码缓存不表示该缓存被选为所属对象的最终几何，也不建立最终材质部件映射。
