## 模型通知后的待处理依赖重试

新增 `project_native_dependency_retry()`，使用当前模型通知状态、已有反向列表和待处理遍历顺序，复现 R1.18 一次完整 `0x1e9640` 重试核心。原始 `0x1efe40` 负责通知，完整文件根输入仍经 `0x199e40` 执行；没有修改指令或代换引用回调。受控宿主配置扩展了实际访问字段，并通过原 Windows 初始化／销毁函数管理配置 `+0x278` 临界区。临时事务指针 `+0x250` 在原始调用前后均为空。
