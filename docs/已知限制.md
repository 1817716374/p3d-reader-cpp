# 已知限制

## 格式与字段

本库面向 BIMBase / PKPM P3D 文件，不保证兼容其他软件使用的同名扩展名。遇到未支持的记录或字段时，会保留原始载荷，并按接口返回未知状态或错误信息。

部分设计参数、枚举、样式标志位及 ABI 填充的业务含义尚未确认。读取出的数值可以保存和展示，不应据此推定未经确认的业务行为。

`ParaCmptProperty` 已支持基础组件属性栈及其递归集合。其他模块注册的扩展类型保留类型编号和原始载荷，并使整体状态为 `partial`；不把它们当作已理解的值。映射输出保留读取条目，尚未求值任意类型键的运行时比较；重复附加属性也保留为有序输入，不冒充已经合并的运行时属性。统一函数只解析保存的模块与操作名称，不执行函数。输入上限为 64 MiB、嵌套深度 80、节点预算一百万，截断、类型不匹配和超限通过状态或解码错误报告。`leading_bytes` 和 `unread_prefix` 分别标明请求值之外与容器内部未消耗的源数据。成功解码不等于完整运行时 Noumenon 已恢复，也不等于已确定活动几何或最终材质绑定。

引用的文件规格已提供源引用、备用查找引用、资源服务附加字符串和默认服务的复合引用规则。显式给定宿主链和文件上下文时，可求值初始查询限制、缺省引用字符串继承以及宿主/当前文件复用；给定资源服务处理结果和完整已打开文件登记表时，还可求值原生倒序匹配、变更探测与复用。宿主自动选择、搜索上下文准备、规格其它服务状态、自定义资源服务、运行时替代引用及跨文件模型加载尚未完整接通；这些输入不能由当前文件中的同名模型代替。`file_specification.status: decoded` 表示该输入视图已解释，不表示目标文件或模型已找到。允许查询或复用文件不等于模型加载成功。

模型目录查询保留原生顺序、重名项及名称查找排除标志。区域设置相关的名称比较需要调用方提供回调；目录中的零长度名称可能需要文件名回退上下文。缺失或损坏目录的模型头重建、运行时目录刷新、版本 5 非空扩展的映射，以及目录位图和部分头字段的业务含义尚未完成。目录匹配结果不替代目标文件定位和模型加载。

`BsplineCurve::native_derivatives_at()` 已提供原生曲线位置与导数约定，支持源节点参数导数、周期归约、有理高阶导数和特殊接缝检查。它遵循原生节点容差，不能保证所有结构有效的源曲线均可求导；零控制权重、分母奇点、数值溢出及超出曲线阶数 26／导数阶数 24 的请求会失败。其双精度递推在高阶、密集节点及导数接近零时可能放大舍入误差，不提供统一的导数误差界。`native_frame_at()` 已提供单条 B 样条的 Frenet／控制多边形／参考轴回退规则，原生零切线可能得到退化矩阵，调用方须检查 `basis_status`。

`native_curve_frame()` 已提供 CurveVector 的首尾、局部导数、跨子项和嵌套数组参考系选择，支持线段、点列、椭圆弧、B 样条及已支持的 Akima、InterpolationCurve、TransitionSpiral 转换路径。未支持的参数曲线片段或其他图元只有在查询实际需要它们时才返回 `not_evaluated`，不当作空项略过。已确认的原生节点容差失败可继续查找其他子项；零权重求导或非有限计算等限制不冒充原生失败返回。源空子项在普通遍历中可跳过，但原生后续导数配对没有空指针分支，库对此返回未求值状态。输入嵌套深度最多 80；成功矩阵仍可能退化，且不保证跨编译器浮点结果逐位一致。自动材质投影上下文、投影范围和最终 UV 映射仍未全部支持。

参数化构件中的 BGFB 已按 P3D 原生类型 20、21 读取路径扫掠与导引放样，包含省略的默认封口标志及嵌套导引组。类型 3、14 的源 B 样条曲线和底层曲面可通过 `BsplineCurve`、`BsplineSurface` 求值，支持开放、周期、非均匀节点和有理权重；这些接口不自动替代场景图形缓存。B 样条曲面提供独立的 UV 裁剪区域查询及下述范围内的派生网格；原生裁剪采样、布尔操作数和其他参数化变体的完整求值仍未全部支持。图形封装及条目已区分各自的样式、内嵌材质、图层和变换，条目按原生 64 位长度划界；未知编码仍保留原始字节。条目局部序号与所属实体重建后的材质部件编号尚未自动关联，额外版本字段仍可能报告未知后缀。

CSG 命令 58 和图形条目类型 10 已解码几何列表、缓存、变换、已知版本二叉树及嵌套 CSG 载荷，保留原生索引及未知载荷。节点和根网格输入接口已提供更新前的缓存／几何选择、首矩阵索引和单位矩阵回退规则；解码入口本身不执行布尔更新、结果生成或缓存有效性判断，专业附加数据语义尚未完全确认。下述求值接口提供各自限定范围内的派生结果。不能把操作数直接当作结果几何，也不能仅凭 `is_old` 标志判断结果正确。节点版本或内部几何不支持时，外层载荷仍可能成功读取，须检查各内部状态。`decode_csg_bytes()` 不调用厂商运行时服务；成功展开载荷不保证原生对象恢复成功。

独立的 `evaluate_csg_mesh_boolean()` 可对两个已构造的封闭三角网格执行并、交、差，并提供输出面来源及角点重心权重。它不自动恢复整棵原生 CSG，不证明与 BIMBase 内核的拓扑划分、容差处理或退化输入行为一致。派生结果可能因内核容差改变微小特征；源几何仍保持不变。输出面来源用于追溯属性，不能替代尚未完成的原生部件材质绑定。

`evaluate_csg_mesh_lists()` 和 `reduce_csg_mesh_list()` 已提供两组操作数及叶子单列表的运算分组、顺序和最初源面追溯。列表交集按对象逐对输出，不能把重叠组自动合并；空计算结果保留为空组，不能当作原生缓存序号。它们使用同一独立网格内核，遇到失败清空结果，不模拟厂商内核错误后的继续处理。完整树更新、节点变换的原生对象作用域及实体离散化仍须另外处理。

`evaluate_csg_polyface_tree()` 已执行多面体树的节点更新、缓存重建、Compound 索引收集以及共享对象的累计变换。低层接口接收已三角化的 Polyface，`evaluate_csg_polyface_archive()` 可以从 BGFB 自动准备这些源网格。当前自动入口支持索引面及隐式三角形／四边形列表，尚不支持行列网格、其他实体或嵌套 CSG。输出及缓存采用派生内核，原生退化处理、空体缓存数量和最终材质绑定不构成等价保证；变换为奇异矩阵或数值不可用时停止求值。源属性池通过源面、角点权重和累计矩阵追溯，不会自动转换为结果的全部属性通道。

`mesh_bgfb_polyface()` 的几何成功状态与属性绑定状态相互独立。缺失属性索引不按数组长度猜绑定；不同颜色池分别验证，不以较长的池掩盖较短池的越界。原始表、未用点、标量尾部及额外字段仍保留。自交／接触的投影面、退化面、未终止索引或超出资源预算时不输出部分网格；不承诺三角剖分与厂商一致，也不自动焊接独立源顶点。

`BsplineSurface::trim()` 支持线段、折线、圆弧、B 样条、Akima、InterpolationCurve 和 TransitionSpiral 边界，以及区域树中的环收集与奇偶填充。环内直接出现的 CurveVector、PointString 按原生转换失败规则记入 `ignored`，不自行展开或连线；原树中的端点仍参与 Open 的闭合检查。其他未支持的边界类型会明确报告。内部零权重或混合符号权重可经齐次细分继续求值；端点零权重、实际分母奇点和大于浮点余量的内部连接间隙仍可能使转换失败，不自动拟合或连接内部间隙。已接收的 Outer/Inner 连续链按最后一点到第一点的直线边闭合；报告保留该派生边，源曲线不改写。达到线段预算、细分深度或浮点精度限制时报告 `incomplete`，查询返回 `Indeterminate`。派生折线及其偏差界不等于原生采样结果，不包含曲面三维误差约束；缓和曲线的偏差界针对拟合 B 样条，不包含其与底层积分曲线的差异。末尾闭合边不做最短跨缝解释，三维端点重合也不自动生成周期带状区域。调用方必须处理边界带和不确定状态。

`BsplineSurface::mesh()` 提供带孔、奇偶区域裁剪及单位参数域求交后的派生三角网格；它不复刻原生缓存的采样或三角形顺序。开放、单向周期和双向周期裁剪曲面支持非归一化节点域，先将边界齐次控制点映射为曲面比例参数，再按该坐标系中的容差离散；源数据保持不变。周期方向不改变保存的 UV 闭合区域：域外部分被裁切，不自动平移复制到对侧，接缝保留独立 UV 顶点。内部全重节点按断裂分片，保留单侧值和独立边界顶点，不根据位置相同而自动焊接。内部节点重数超过阶数、不同断裂归一化后无法区分仍不支持。零或混合符号的曲面权重通过逐节点矩形的 Bernstein 区间细分确认分母非零后，可继续网格化；不是只检查网格采样点。真实分母零点、区间精度或工作预算不足仍返回未完成。当前分母判定覆盖整个有效参数域，即使奇点位于被裁剪掉的区域，也不会跳过；这与裁剪边界曲线的权重限制是不同环节。精度选项约束 UV 边界近似和三角形边长，不提供三维弦误差界。数值无法可靠求交、细分精度不足或预算耗尽时返回 `incomplete` 和空几何，不以部分网格表示完整曲面。此接口不提供封口、材质部件映射或自动场景替换。

Akima 转换遵循原生 6 至 5000 点及过滤后至少 6 点的要求，首尾各两个保留点用作切线支持。转换错误由 `_akima.status: invalid` 或 C++ 异常表达，源点仍保留。非有限坐标、距离或参数范围溢出明确拒绝；不补造辅助点，不将无效插值输入退化为折线。派生 B 样条与活动场景、导引曲面和布尔操作之间的完整求值关联尚未全部接通。

`InterpolationCurve` 采用 BGFB 原生读取路径的固定三次转换，保留但不使用源阶数、节点和端部切线，不能用作接受任意阶数或显式端部切线的通用插值器。过滤与闭合准备后最多 4998 点，闭合标志可按原生退化规则转为开放表示。失败通过 `_interpolation.status: invalid` 或 C++ 异常表达；不以折线代替失败的插值曲线。该接口与其他参数化操作及活动场景的完整求值关联仍受上述限制。

`TransitionSpiral` 支持原生工厂类型 10 至 14 的底层求值及 `native_fit()` 拟合 B 样条转换，拟合结果也用于曲面裁剪边界。底层积分的误差界不含浮点舍入；拟合器的收敛条件只衡量弧长参数变化，不提供底层曲线与拟合结果的几何误差界。`native_fit_input()` 的积分误差值同样只是原生估计。库保留短点列的原生边界方程和反向区间的半径符号规则；不能把拟合参数直接代入底层求值，也不能假定反向拟合等于正向控制点倒序。超出数量/积分预算、退化参数、数值溢出或 30 次内未收敛时抛出异常。活动场景的完整求值关联仍未提供。未知类型、无法确定长度或不满足原生曲率/方位角条件的数据保留源字段，并在 `_spiral` 中报告错误。

`SectionLoft` 提供 BGFB 源放样的 B 样条侧面；`cap_regions()` 可按原生端部提取、闭合检查和方向规则构造底、顶封口边界区域，`mesh()` 可对已支持侧面及平面封口生成连接网格。封口区域成功不保证内部边界连续、共面或实体有效，不自动补线或投影。网格接口目前不支持非平面盖面、需要新增交点的自交/接触裁剪环及退化三角形；无法保留盖面全部边界采样时明确失败。精度选项约束侧面 UV 边长，不提供三维弦误差界；只报告索引边连接和方向，尚未检测整个实体的空间自交或顶点流形性。原生 Open 的独立首末导引不自动焊接，中间可能仍有开放边。其 B 样条边界支持开放夹持、普通周期和特殊闭合节点表示，支持非零的正、负或混合符号控制权重及连续内部节点，支持次数 1 至 25。按控制多边形长度连接后的闭合导引支持原生关闭及重新打开，包括普通周期转换、特殊直接打开和端点检查失败后的循环回退。周期打开请求节点参数零；源有效节点区间不包含零时失败。支持按原生容差吸附到接缝附近的已有节点；多个不同节点被判入同一容差组、导致打开结果仍非夹持的情况尚未接入侧面构造。某些重复接缝位于节点域末端的非归一化表示也仍未支持，不进行越界控制点复制。开放非夹持、内部全重不连续、源零控制权重、联合区域及嵌套导引尚未支持；升阶、节点兼容或关闭转换生成零中间权重时同样可能失败。侧面构造产生的零权重按原生乘积规则保留，构造成功不保证曲面处处可求值。网格生成前逐侧面验证整个参数域的有理分母非零，遇到奇点、数值不确定或验证预算耗尽返回未完成和空几何。封口网格支持混合符号的有理边界，按实际节点区间验证分母非零及整条曲线到平面的距离上界。验证不能完成时返回未完成，不以控制点或采样点共面代替证明；侧面构造产生的零权重端部控制点可保留在封口区域中，并参与完整分母及平面界验证；端点采用原生曲线求值的零权重回退规则，因此区域闭合成功仍不保证分母非零。零权重边界的原生封口 UV 查询仍受其参考系及范围求值限制。极端尺度、节点聚合和浮点精度不足可能使构造失败。Akima、InterpolationCurve、TransitionSpiral 在这条原生放样转换路径中不返回 B 样条对象，因此明确拒绝，不能自动用裁剪路径的拟合缓存替代。源表仍可通过底层接口完整读取。命令流放样的网格支持范围与此显式参数曲面接口分别说明。

变电站 `ElecParaData` 支持外层版本 0、1 和 `PBWJData` 版本 0 至 2，包含非空截面、柱参数、桁架梁及人字柱集合。`SubsColPar` 支持版本 0 至 6，`TrussBeam` 支持版本 0 至 5，`HumanColumn` 支持版本 0 至 4；嵌套的 `TrussBeamPar` 支持版本 0 至 3，其中版本 2 不保存成员载荷，返回空 `members` 和 `member_payload_status: not_serialized`，不补运行时默认值。遇到未支持版本或损坏的内部长度时，保留完整原始载荷并报告字段解码错误。

截面组中的字符串没有保存代码页标识。库保留原始字符串字节，仅为 ASCII 内容直接提供 `text`；其他内容由调用方按来源代码页解释。截面专用参数的成员位置和数值已按原生布局展开，但并非所有成员均有业务名称。

原生可见性与视图规则尚未完整支持。历史缓存记录保留在底层接口中，不额外加入活动场景；活动场景不保证与原软件某个特定视图的显示列表完全相同。

支持的图形记录通过构件 `metadata.display_state` 提供永久隐藏标志。此标志不等同于视图可见性；图层、模型链接、裁剪和临时显示状态仍需结合各自的数据。未支持的头布局明确标记 `unsupported_header`，不会从任意记录的同一偏移猜测显示状态。

图层组合的覆盖位图及同步模式已通过底层属性接口展开。`layer_tables().group_states` 可按模式及覆盖位计算颜色、线型、线宽、显示、打印、冻结和透明度，并提供每项原生来源；同步中的成员增删也已表达。名称表更新、其他样式、模型链接继承及视图条件尚未全部合并，因此此结果不等同于最终视图可见性。

图层独立记录的版本 1 至 7 可读取名称、描述、显示、打印、冻结、访问模式、颜色索引、线型、线宽和透明度；版本 4 至 7 还提供业务代码。其他版本明确标记未支持。图层表成员、覆盖属性来源和模型到组合表的 ID 引用可通过 `layer_tables()` 读取；尚未确认的字段继续保留，链接路径的完整运行时解析及最终继承结果仍未求值。

命令流中的图层 ID、样式继承标志及填充样式块可读取，但尚未完整计算图层继承和最终显示样式。涉及未支持继承条件、渐变填充或显示上下文时，外观摘要的 `color.rgb` 返回 null，`color.source` 说明原因。线型修饰参数及复合绘制状态的存储布局已展开，部分字段和功能码仍未确认含义。

## 几何与坐标

## 错误与歧义

视图链接顺序可在明确的原生链接列表和候选上下文下协调、构造默认值并排序；候选收集可沿已提供对象图的父链接链筛选归属。普通加载入口的链接排序及“先协调、再排序、必要时构造默认顺序”已支持，保留原生相等项排列与重复来源。模型自动选择、运行时对象图的自动构建、链接列表的外层加载、图层和显示样式叠加、完整裁剪与最终可见性尚未全部接通。顺序接口的 `resolved` 或 `ordered` 不表示完整视图已重建。

引用祖先重复判断已支持显式加载上下文中的原生条件与层级阈值，但全局设置、文件提供者状态及宿主链尚未自动恢复。宿主排除筛选、普通加载状态决策及活动／副列表插入规则也可在明确上下文下求值；后代门控及按原生顺序搜索已提供的活动引用图也已支持，区分对象身份、虚拟类别和独立运行时标志。已确认普通模型／引用实现及父关系时，可自动推导后代搜索门控和所属模型起点，但完整图仍需调用方提供。输入回调及从文档构造完整引用图尚未自动接通，不能把 `repeated: false` 或原生返回码零当作引用已经成功加载。列表判断保持原生区别：活动列表不去重，副列表只按次级键阻止重复追加。

已支持从类型 13 记录恢复普通输入成功后的初始运行时控制字，并在明确的文件规格下构造搜索查询；它不能替代外层加载、服务处理或回调已经改变的对象状态。引用掩码记录的首项选择和四个存储字已提供，细分用途及最终视图应用仍未全部确定。

普通初次输入的主、次标志已接通矩阵缩放重算、控制依赖首项选择和裁剪深度检查，并可用于记录驱动的加载决策。控制依赖编号保留为原生 64 位引用，不表示其目标对象已找到；外层加载和回调后的标志仍需实际上下文。

引用嵌套深度已关联到源字段，可沿明确父链计算剩余深度和位 14 输入限制，并判断该轮是否处理视图顺序。新建普通引用节点可从记录初始化，但该节点尚未连接目标根模型或加载自身活动链接；此接口不等于已自动恢复最终跨文件引用图。

单条引用请求已支持登记表门控、活动/副列表按实际输入编号返回已有对象。它要求调用方提供当前完整登记表及所访问的对象图，保留原生身份和顺序；不能由初次登记表推断全部后续加载状态，也不替代批量收集或目标连接。

文件取得后的目标模型选择和缓存查询已接通，支持默认模型优先级、显式编号、名称目录顺序、有符号编号守卫及专用模型槽。模型构造、资源提供者刷新、实际挂接及后续内容加载尚未自动执行；提供者的中间对象不能代替完整构造结果，`matched` 也不表示已完成这些后续步骤。

对象图可通过明确连接身份共享目标模型信息，根查询和后代匹配已接通；反向引用列表的直接增删规则也已提供。实际连接身份仍需可靠来源，列表操作不包含挂接/解绑时的通知、子引用清理及其他回调效果，完整自动挂接过程尚未完成。

文件加载失败可能抛出异常；部分字段或几何失败则保存在结果中。调用方应同时检查：

- 记录或字段中的 `decode_error`、`parse_error`、`field_decode_error`、`topology_decode_error` 等诊断信息。
- 场景元数据中的 `errors`、`library_errors`，构件与定义中的 `unknown`、`notes`。
- 对象、绑定、层级边、块引用和材质的 `missing`、`ambiguous` 等状态。

CLI 退出码为 0 表示执行完成，不表示所有字段都已被理解。某项数据保留了原始字节，也不意味着它已被转换为可直接使用的几何或语义对象。

## 数值与接口

标准 JSON 文本不能原样表示 NaN / Infinity，导出时写为 null；原始字节仍保留，C++ 内存中的浮点值不因此改变。超过 2^53 的整数应使用能够无损表示它们的目标类型，避免通过 JavaScript Number 往返。

对象 ID、模型 ID、定义索引和 `source_key` 均属于当前文档。组合多个文件时，需要增加调用方自己的文档身份。

当前 `0.x` 接口尚未承诺稳定 ABI；静态库应使用兼容工具链构建和链接。

模型边线缓存已支持属性索引选择、版本 51 的压缩模型分块、子模型树、字符串登记表、图形区段和代理实体中的已有格式命令；可选模型头已接入单位、坐标和已有视图标志解码，引用参数已提取保存的标志、矩阵、比例及点。最终引用连接及显示规则尚未接通；模型头和引用参数中的其他字段、组件字段、可选 96 字节块、显示头及线型修饰仍按源载荷或来源位置提供。参数解码不代表已对实际引用对象应用；结构读取状态也不保证命令层的每种几何都能重建。其他不低于 15 的缓存头版本仅读取公共头，不解释后续模型。

索引 65535 已支持引用目录路径、引用摘要、实体编号、最后修改时间和关联条目之间的源索引。已提供实体状态比较与原生关联集合选择查询，但实际对象匹配、当前摘要生成及显示回调尚未自动接通，需明确上下文才能求值；源索引存在不代表关联有效。修改时间采用 SDK 声明的本地时间基准，不能直接作为 UTC 时间戳。原生没有声明的实体合并或几何复用不会由库自行引入。

缓存状态摘要已支持字段解码和原生比较规则。尚未重建完整运行时摘要输入及所有缓存有效性条件，摘要匹配不代表缓存可用于当前场景。
