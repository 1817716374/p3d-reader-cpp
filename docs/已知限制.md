# 已知限制

## 格式与字段

内部多边形 UV 准备支持独立单位范围、保持长宽比的单位范围和距离范围；其他模式保留原投影坐标。断开项继承前一个 UV，首项为断开时使用零坐标。距离范围独立保留；退化坐标范围导致变换失败时不强行归一化。零点或单点输入的原生面距离范围未写入，库明确报告未完成。此步骤尚不包含端盖构建器的属性索引写入及整实体装配。

内部折线端盖输入已支持按原顺序组装外环和内环、逐环反向、原生闭合、线段细分、相邻近点压缩及局部坐标系准备。环的角色来自输入次序，不按面积或包含关系重排；起端反向不改变环序。细分保留原生计数偏移与单段一百份上限，多环末尾的断开标记继续保留。已提供可追加交点坐标的投影三角化通路，但最大边长约束下的内部细分、完整端盖属性生成与成对发布仍未贯通，成功状态不证明环有效、共面或实体封闭。

内部投影多边形三角化保留源坐标槽位并按原生顺序追加交点。先沿拓扑顶点传播已有编号，缺号时追加当前角点的图坐标；不按坐标另行合并。输入和输出均使用调用方给定的坐标系，普通点经过原生变换往返，因浮点运算可能与输入值有细微差异；断开标记保持原值，局部 Z 不会强制归零。该通路采用固定三边面限制，未包含最大边长的自适应细分或端盖构建器属性写入。原生成功、全部输出为三角面和最终实体完整是不同状态。

内部样式 `1、3、4、5、6` 的网格已接通进入构建器前的条件准备：按源池是否缺失决定法向、UV、面记录及边链生成，依原生次序完成复制、准备、条件拆面和构建器合并。已有非空属性池不会仅因索引缺失而被替换；UV 请求同时控制缺失面记录的生成。近似法向采用原生单边 `30°`、累计 `90°` 默认值。最大面边数按原始 32 位有符号值比较，`0` 不表示无限制；仅要求凸面不会单独触发准备流程。准备已被其他条件触发后，才按源面凸性决定是否强制三角化。各步骤仍受对应原始样式的读取和回写限制。

各准备步骤的失败和不完整诊断会保留，后续原生步骤仍按次序尝试；最终构建器返回成功不代表之前的准备完整。各源准备结果单独返回，未传入最终构建器的颜色或逐面扩展使整体完整状态为假；若原生复制本身已省略部分值，可从未修改的源输入取得原值，并查阅对应诊断。入口要求已应用放置变换的坐标，不预先转换原始布局。若原生条件没有触发布局转换，准备结果仍可能是连续面块或行列网格；当前最终索引式装配无法完整表达这些布局，通过 `untransferred_raw_layout_sources` 报告来源，并将整体完整状态置为假。完整实体端盖及上层材质关联仍未完成。

内部逐面访问支持原始样式 `1、3、4、5、6`，分别保留索引式、连续面块和行列网格的读取规则。连续面块可能返回法向、UV 和颜色值而没有相应属性索引；不为其补造索引。行列网格采用全局行宽，始终尝试读取属性，并将闭合重复数限制为十；其三角面起点、颜色选择与先转成索引式网格后访问不同。未被原生访问器消费的单精度颜色、连续面块的面记录，以及被整数颜色遮蔽的网格颜色表均明确报告。访问结果保留各数据池的原始表示，完整状态仅针对本次访问范围。

原生行列访问的边界判断可能允许随后发生数组越界，连续面块也可能尝试闭合空属性前缀；库拒绝这些实际不安全的读取。全局行宽为一时拒绝原生除零路径。逐面访问不会修复源布局，也不证明文件级关联、实体端盖或最终材质绑定完整。

内部有类型网格的逐面法向和 UV 生成保留原始样式，并按“读取一面、生成属性、再读取下一面”的次序工作。后续面会看到已经更新的池和索引；属性生成通路消费后释放逐面值，保留来源位置和诊断。它不会预先冻结全部面的属性快照。准备流程的 UV、近似法向、面记录与边链步骤均使用有类型通路；各步骤保留自身的支持边界。

原生逐面生成要求点索引数组非空，即使连续面块本身能够从点池读取也不例外。回写使用访问器的实际索引位置；位置超出目标数组时保留已生成值并报告跳过写入，不扩充源布局。行列网格没有提供这些位置，实际需要读取时明确拒绝，不能仅凭支持网格遍历便宣称支持该生成路径。其他未消费的颜色或面记录仍会影响完整状态；源数据和独立材质元数据保持原值。

内部有类型邻接关系和近似法向已支持索引式网格及原始连续面块。共享图构造使用访问器的顶点编号、边可见性和索引位置；坐标相同但编号不同的点仍独立。近似法向沿用已生成的逐面结果，再按原生邻接扇区平滑，保持法向分配顺序、角度阈值及可选边可见性更新。颜色、逐面材质列表、名称及布局元数据不会因平滑而丢弃。

邻接查询会尝试读取原生全属性通道。连续面块在逐面法向生成后，原生访问器可能只读到部分法向值；即使拓扑和平滑过程返回成功，查询中的不完整读取仍单独保留，并使整体完整状态为假。行列网格缺少原生邻接构造需要的索引位置，实际读取时拒绝。上述通路不进行流形修复，也不表示完整实体端盖、材质覆盖或所有文件入口已接通。

内部网格查询复制已保留逐面 UV、64 位材质编号、平滑组、面记录和边链，并区分构造默认值与源查询值。该复制不是整个对象赋值：各索引按源点索引数量读取，四种颜色池共用原生颜色查询计数，目标的向量标签与行宽保持原值；空源数组清空目标数据但不自动关闭原有活动标志。纹理编号保留目标值，源编号不同时会报告信息未完整传递。名称按原始 UTF-16 单元处理，保留原生复制中逻辑长度包含终止零的行为。数组越界读取被拒绝，截断或省略的数据会记录在结果中，源输入不变。

逐面扩展数组独立于通用参数池和面索引。复制与拆面不会根据数组长度推断工程含义，也不会擅自给新增三角面重新分配材质编号或平滑组；这些扩展数组与上层部件的完整关联仍需单独确认。内部复制的完整状态用于报告值和布局元数据是否遗漏，不代表已经验证整个实体或材质绑定。

内部有类型网格已贯通布局转换、通道启用、逐面读取和按边数限制拆面，分别传递点、法向、UV、颜色和面记录的原始索引，保留各数据池及边链。法向和 UV 仅在自身索引为空且池大小与点池一致时沿用点索引；颜色与面记录没有这一回退。颜色读取按非空的双精度 RGB、单精度 RGB、整数颜色、颜色表依次选择，但原生颜色计数按活动的单精度 RGB、双精度 RGB、整数颜色、颜色表选择；二者不一致时可能截断读取，若导致访问实际数组之外则明确拒绝。各颜色表示不会被转换或合并。

逐面读取保留独立属性索引及闭合重复项。原生在补闭合点后检查面点数，因此部分坏点引用仍可能通过原生检查；库保留可读前缀并报告不完整，不将补闭合点当作修复。固定长面的前导零会停止遍历，可变长面的连续零则会跳过。拆面结束按原生规则清零全局行数，其他池的行宽保持原值。该通路面向已取得的运行时网格数据，完整实体准备、端盖装配及所有文件入口仍需分别确认。

内部网格布局转换已支持原生样式 `1、3、4、5、6` 的索引面、连续三角形／四边形及行列网格。固定块按各索引数组自身的行宽转换，保留符号、压缩连续零分隔符，并报告舍弃的不完整尾块；原本不带末尾分隔符的可变长度数组不会自动补零。行列网格采用点池的行宽元数据，部分末行不生成缺角点的面。索引生成保持原有活动标志和其他行宽元数据，后续“按现有数据启用通道”是独立步骤；该步骤只检查池和索引数组是否非空，不证明索引有效。转换接口处理运行时布局元数据及索引，池内值由调用方保留，不等于所有文件记录和实体入口已接通。

内部网格面查询按原生点访问器统计最大面大小，并按空间叉积与相对转角容差判断凸面；该判断不检查共面、自交或封闭性。三个及以下角点的面在网格凸面查询中直接接受，不能据此判断退化面有效。查询提前遇到非法点引用时，原生凸面结果仍可能为真，须同时检查完整状态。查询只访问点数据，不以无关属性通道是否可读决定凸面结果。

准备好的面三角化接口支持显式边数上限，低于三的上限按三处理。未超过原生阈值的面保持原角点与独立属性索引，甚至可能保留凹多边形；超限面再进入原生三角化分支。因而操作完成与“输出全部是三角形”分别报告，默认上限仍为三。此参数不替代外层凸面要求，也不表示原始网格样式转换和完整实体构造已完成。

内部网格构造器已连接准备好的网格查询数据到统一坐标池、独立索引、面数据与边链，并接通外层条件准备和条件三角化。调用方必须先提供已应用原生放置变换的坐标；完整端盖及路径扫掠实体网格仍未贯通。此装配入口按原生行为不传递颜色索引，有颜色索引输入时明确报告不完整；索引不匹配、缺失映射键或活动通道未对齐也不会被当作完整结果。装配完成不证明几何封闭、面域有效或整个文件已完整解析，源几何不会因此自动去重。

逐面属性生成会替换所选属性池及其索引，不修改源查询数据。局部坐标系失败时，原生逐面法向保留零索引，UV 则为每个角点写入独立的零坐标；库保留这些结果并报告不完整。UV 回写现有面记录范围时沿用原生直接下标规则，不修正面编号；负值或越界值被跳过并报告。零面积也可能形成原生可用坐标系，因此生成成功不能证明面域有效。逐面法向不等于依赖邻接和角度条件的平滑法向。

内部网格邻接转换支持准备好的索引式查询数据，按原始顶点编号连接半边，不以坐标相等推定共享。原生规则会配对同一端点组内恰好两条边，即使方向相同；库保留该行为，并对顶点环标签不一致报告不完整。三条以上共享边通常形成独立边界，但四条共享边中的特定退化三角形有原生专门配对规则。邻接转换成功不证明网格为流形或闭合；未经支持的原始网格样式仍需先转换。

近似平滑法向先生成逐面法向，再沿原生邻接划分顶点扇区。单边角度使用弧度，并包含原生 `1e-5` 角度余量；扇区是否合并还取决于法向平均值和累计夹角，不按面面积加权。相同向量可保留为不同索引，边可见性按索引身份决定；仅在明确要求时替换坐标索引的可见性符号。中途失败的返回数据可能保留新生成的逐面法向，而非输入法向，源输入始终不变。原生返回成功仍可能存在未访问角点或不一致的邻接，须另外检查完整状态；该操作不会自动应用于源文件中已有的显式法向。

内部边链生成按源顶点编号登记可见边，并按面遍历顺序输出独立的双顶点记录，不自动连接成长折线或合并重合坐标。第二次遍历沿首次遇到的对应边输出方向，该边自身可能不可见。拓扑类型 `24` 保存零基顶点编号，类型 `4` 保存原生共享面编号；这些面编号对至少三个角点的面按 `1、3、5…` 递增，与现有面记录编号不同。多次出现的同一边按原生规则仅保留首末可见来源面，不能据此认定流形。已有边链时生成操作返回原生失败并保留输入；遍历提前结束时仍可能返回原生成功，须检查完整状态和未访问角点诊断。

有类型面记录生成直接使用源样式的访问器，不执行布局转换。索引式读取位置是索引数组偏移，连续面块和行列网格的读取位置是面序号；原生分组仍用其原有终点计算式。因此特殊布局可能留下未分配的面索引，库保留原生结果并报告不完整。范围查询从指定位置直接开始，不先读取更早的面；到达终点的下一面仍会先加载属性，再决定是否纳入统计，实际越界读取仍被拒绝。此类查询的完整状态仅针对 `visited_range`，不证明整个网格覆盖。无 UV 或 UV 局部退化时，距离参数范围可保持原生空范围，不补默认纹理尺度；缺少应参与距离统计的 UV 时也不发布先前部分统计。距离尺度是原生局部采样的统计量，不代表精确曲面度量。

有类型边链生成按原生全属性访问器执行两遍带一个闭合重复项的遍历；使用声明的角点数和实际客户端顶点编号，不将缩短的可读前缀自动封口。末点引用无效时，即使逐面读取通过了原生补闭合后的数量检查，边链消费仍可能因实际越界而被拒绝。行列网格能够提供边链与面范围所需的顶点和值，其缺失索引位置的限制仍适用于需要该位置的法向回写及邻接构造。生成边链不会自动开启边链活动标志。

内部路径面片已连接支持范围内的接缝求解、首尾边界协调、活动边界选择和整链裁剪。成功状态须从完整构造结果读取，不能由某个准备步骤成功推定。空的内部接缝段会导致原生越界迭代，库明确拒绝该输入；单点段及重复端点按原生规则保留。输出运行时 UV 缓存仍受原生采样和浮点容差约束，不提供精确曲面交线或误差认证。

接缝单个 U 位置的初始平面求交通路包括常 U 等参曲线、交点顺序选择、空间重合判断和端点吸附。底层返回 `fallback_required` 时，保留两条曲线交由已连接的双曲线回退处理；该中间状态不是无交点或完整接缝成功。自适应采样和整链消费仍可能因原生失败、数值限制或资源预算而停止，不能将单个位置求解成功等同于完整接缝曲线。

内部双曲线 XY 求交已连接固定采样、折线候选、Newton 修正及独立对角项回退，支持原生 B 样条分段遍历和全曲线比例换算，并用于接缝回退的共面变换与装配。每对 Bézier 段只修正原生保留的前 100 个候选，重复交点仍保留，不返回重合区间；这不是精确的全部根求解保证。修正成功也不能单独证明最后参数对应的两点重合。

本库面向 BIMBase / PKPM P3D 文件，不保证兼容其他软件使用的同名扩展名。遇到未支持的记录或字段时，会保留原始载荷，并按接口返回未知状态或错误信息。

CSG 中的拉伸、直纹扫掠、旋转扫掠和导引放样按源曲线规则逐次变换并重建，支持已确认的椭圆轴塌缩替换。生成的新网格由独立快照提供来源，不用一个累计矩阵代替源重建；其他曲线类型及重建限制仍按各自接口报告。

路径扫掠 `P3DSweptBody` 已支持源截面／路径的条件构造、复制判定及源曲线放置变换。内部整体曲面通路已连接支持范围内的源曲线组转换、截面定位、路径分段、曲面拼接、方向和端盖区域。独立面片通路已接通支持范围内的路径准备、切分和分支定位，已实现单分支面片链生成、双侧组合及接缝描述，已连接直纹接缝的控制线求交、平面回退和高阶延长拼接，已连接整链裁剪收尾、路径分组、曲面组合、端盖和原生面编号，并通过 `reconstruct_bgfb_swept_body()` 提供支持范围内的参数曲面结果。仍不提供完整实体网格，未接入 CSG 的实体离散化。生成的未裁剪曲面支持逐列转换 V 向周期表示，保留齐次权重及 U 向参数；闭合失败或各列控制点数不一致时保留整张输入曲面，报告区分原生返回码与实际是否应用转换。整体曲面通路的原生斜接使用控制线延长求交；平行时可能保持不同端点，闭合标志也不保证几何封闭，库不会把它改成自动焊接或修补。

独立面片的单段曲面生成已连接上述采样准备：按各控制行的平均参数查询坐标架，以控制点和曲线上位置的偏移及平均曲率修正截面方向，保留截面 Z 坐标，生成后统一施加齐次权重。回退分支使用输入路径首末控制点的原生带保护除权重结果生成直纹曲面，曲面权重仅继承截面；它与一般曲率补偿分支的权重规则不同。已保留外层回调与内部工作副本的查询顺序、刚性／非刚性坐标架更新及规则线数量。单段生成已接入按源顺序排列的分支面片链，已连接双侧组合，已连接直纹接缝的控制线求交、平面回退和高阶延长拼接，已连接整链收尾、分组和端盖，公共重建结果仍须检查状态；这不证明任意源路径均可重建。

独立分支面片链保留分段前后的工作副本及查询顺序，记录相邻面片的归一化切线、接缝分类和平面，平面法向不额外归一化。源闭合标志或几何首尾闭合均可触发末端接缝；平行切线及接近零的接缝法向按原生规则省略平面，不自动焊接。几何闭合且仅有一个活动节点区间、首末切线不平行时，先尝试插入原始节点值 `0.5`；节点域外插入失败仍继续分段，不将它改写为比例参数中点。周期插入保留闭合存储、外部节点和跨端控制块，特殊控制点偏移还要求原生端点及权重条件成立。面片链这一局部步骤返回未处理接缝的独立曲面及对应描述，完整重建入口继续执行接缝和裁剪处理。

双侧面片组合按原顺序生成两侧分支，前侧节点倒序并同时反转曲面 U、V 方向，后侧保持原序。接缝分类、切线和平面依照原节点关系迁移，闭合接缝与新分支接缝冲突时报告原生失败。曲线工作状态按实际源引用传递，不把几何相等的不同源合并；接缝存储的原生共享关系也予以保留，后续写入会反映到所有共享位置。若原生操作使共享引用失效，报告明确标记该状态，不将其当作可继续求值的接缝。组合结果仅表示接缝处理前的状态，尚不构成完整扫掠实体。

内部接缝处理已支持相邻两面均为 V 向二阶时的控制线直接求交分支：逐列使用无限延长线求最近点，保留两侧各自的结果，按原生近等判据决定是否直接改写控制行；不按线段范围裁断，也不把近等点平均或焊接。平行或退化控制线导致原生失败并清空整链；错开的控制线转入平面回退分支，沿各自接缝切线投影控制行。射线方向和平面法向保持原尺度，保护除法失败时保留原点；回退距离超过原生条件时标记跳过，保留对应工作状态，不把它改为失败或自动修补。带权控制点使用原生保护除法，输出按原生权重索引重加权。接缝遍历保持节点顺序，末节点接向首节点；这一局部处理的结果由完整重建入口继续执行整链收尾；单独完成控制线处理不表示实体已完整。

高阶面片已实现接缝平面投影、端点控制行工作状态和后续延长量计算。延长量来自两侧切线延长线的最近点参数，只累计正值，与到平面的投影距离分开；不要求两个最近点相同。平行延长线按原生规则失败。高阶延长按原控制行重建带权截面，沿接缝切线生成直纹片、升至原次数后拼接；后侧延长片先反向，再升阶并前置拼接。高阶延长参数至少取 0.1，然后按原生顺序乘 1.5；混合输入中的二阶侧直接移动控制行，使用原始正参数最大值，不套用高阶下限。两侧全部成功后才发布当前接缝结果，仍需后续整链收尾。

高阶延长所需的内部 V 向曲面升阶已支持未裁剪、开放 V 的曲面，目标次数不超过 25。节点方案由第一列统一确定，各列分别保留自身求导时的权重舍入；U 向周期状态、节点及原规则线数量保持不变。同次数直接复制，也可保留周期 V。实际周期 V 升阶及裁剪边界处理尚未接通；开放延长片升阶已接入接缝拼接。非钳制节点的未定义存储、求导容差失败、非有限运算或资源预算不足时明确失败。原生曲面升阶不预先归一化节点域，非单位节点域不能一概视为保持形状的通用升阶操作。

延长片组合使用原生的强制连续、非长度重参数化分支，舍去后片首控制行，不检查或修复端点间隙。输出沿用前片 U 向参数、有理标志和边界原点标志；拼接内核先按控制行数设置规则线数量，接缝调用方再将对应规则线数量改为原值加一。第二侧延长截面使用第一侧保存的 U 向参数。两侧指向同一曲面时，第二次拼接接着第一次的结果执行，不复制为两个互不关联的曲面。实际周期 V、裁剪曲面及不满足列访问条件的布局仍明确拒绝；这些接缝操作不代表最终实体、端盖或材质部件映射已经完成。

内部子曲线截取支持 2 至 26 阶 B 样条，保留非单位节点域、齐次权重、重复节点和断口。超过整个参数域的请求按原生整曲线复制处理，部分截取采用原生节点插入与归一化；闭合曲线先按请求打开，反向请求保留工作曲线反向与结果反向两个步骤。闭合曲线打开后仍使用原始节点距离，因此非单位域可能触发原生域外失败，库不自动改写为另一种截取结果。极短区间、归一化失败及带几何的失败状态分别报告；零控制权重导致的除权重失败、非有限运算、无效访问范围及资源超限明确拒绝。截取结果不保证拓扑有效，也不代表完整扫掠面片链已接通。

内部 B 样条路径分段按原始节点域判断近零区间，支持阶数 2 至 26、非均匀节点及有理权重。原生准备过程保留前段末控制点，后段首控制点即使不同也不独立存入处理链；库会记录被替换的齐次控制点，源曲线保持不变。各有效段在最终曲面的 V 方向占相同区间，不是按弧长分配。只有一个有效段时走直接复制分支，闭合源标志不会额外触发首尾修补。全空区间、非有限运算或预算不足明确失败；生成有限控制网格不等于已证明曲面无奇点、自交或退化。

扫掠内部已统一线段、折线、椭圆弧和 B 样条基本曲线的原生转换。线段保留端点；椭圆弧与原生裁剪边界共用角度调整、权重及闭合表示算法；B 样条直接保留原控制点、权重、节点域和闭合状态，不先归一化或重新开口，也不强制消除内部断点。转换成功不代表后续扫掠求值一定成功。这里的原生类型接收范围不同于裁剪边界，不能把 Akima、插值曲线等自动当作已支持的扫掠源基本曲线。

内部组合内核支持同阶开放 B 样条的原生拼接，包括不连续接缝、按控制多边形长度分配参数及过短曲线的舍弃分支。接缝判断使用除权重后的首末控制点；拼接不统一双方权重比例，也不自动补断口。长度计算保留除权重后再乘回权重的浮点运算顺序，输入对象保持不变。节点归一化保留原生的极小区间失败行为；非有限计算、无效节点布局和资源预算不足明确失败。

内部两曲线组合已连接源参数零处的周期开口和较低次数曲线的升阶，再按原生规则拼接。实际升阶支持目标次数不超过 25，保留源节点区间、按容差聚合节点、内部断点的左侧求导、齐次控制权重及首末控制点恢复规则。同次数直接复制，可以保留实际升阶时不能处理的零权重或非钳制布局。实际升阶需要节点容差所用的除权重计算；外侧节点使原生新节点数组未完整写入、聚合后的求导窗口无效或工作预算不足时明确失败，不推测缺失节点。组合仍受周期开口本身的支持范围限制。

内部扫掠源曲线组已接通类型 0 至 3 的成员转换、依次组合和整体闭合请求。首尾判断使用源折线端点、源椭圆角度和原生 B 样条点求值，不能由转换后端点或组类型代替。原生关闭失败时保留开放曲线并记录失败；两控制点线段可返回成功而仍为开放状态。一般关闭支持非单位、非钳制节点及内部断点，按保存的齐次端点和权重决定是否继续；成功时可能改变节点域，不自动恢复原始参数区间。报告分别给出源首尾判断、关闭成功状态和结果闭合标志，均不证明中间连接、平面性或实体有效性。

内部整体曲面通路的多环截面转换支持简单组，以及类型 4 中首尾闭合的类型 2／3 子组，保留成员顺序、重复环和原有类型，不推断空间嵌套关系。该转换尚不支持联合区域、嵌套基本曲线组、空曲线组和空控制点 B 样条；多环共用累计工作预算。这些限制不等同于独立面片通路的参考截面和源分组规则。

其中折线到 B 样条转换保留原生一次拟合：按弦长参数化，以 `1e-5` 容差累计检查原输入点上的删减误差，并保留原始参数、控制点来源和删减记录。它可能删去折线顶点，也可能保留已经共线的控制点；不会重新尝试原生已拒绝的候选点。两点直接构造直线，更多点可能因极短路径、重复参数或端点容差而无法插值。密集节点导致未支持的删减状态、非有限运算或资源超限时明确失败，不自动合并源点。该转换已用于上述内部源曲线组转换。

部分设计参数、枚举、样式标志位及 ABI 填充的业务含义尚未确认。读取出的数值可以保存和展示，不应据此推定未经确认的业务行为。

`ParaCmptProperty` 已支持基础组件属性栈及其递归集合。其他模块注册的扩展类型保留类型编号和原始载荷，并使整体状态为 `partial`；不把它们当作已理解的值。映射输出保留读取条目，尚未求值任意类型键的运行时比较；重复附加属性也保留为有序输入，不冒充已经合并的运行时属性。统一函数只解析保存的模块与操作名称，不执行函数。输入上限为 64 MiB、嵌套深度 80、节点预算一百万，截断、类型不匹配和超限通过状态或解码错误报告。`leading_bytes` 和 `unread_prefix` 分别标明请求值之外与容器内部未消耗的源数据。成功解码不等于完整运行时 Noumenon 已恢复，也不等于已确定活动几何或最终材质绑定。

引用的文件规格已提供源引用、备用查找引用、资源服务附加字符串和默认服务的复合引用规则。显式给定宿主链和文件上下文时，可求值初始查询限制、缺省引用字符串继承以及宿主/当前文件复用；给定资源服务处理结果和完整已打开文件登记表时，还可求值原生倒序匹配、变更探测与复用。宿主自动选择、搜索上下文准备、规格其它服务状态、自定义资源服务、运行时替代引用及跨文件模型加载尚未完整接通；这些输入不能由当前文件中的同名模型代替。`file_specification.status: decoded` 表示该输入视图已解释，不表示目标文件或模型已找到。允许查询或复用文件不等于模型加载成功。

模型目录查询保留原生顺序、重名项及名称查找排除标志。区域设置相关的名称比较需要调用方提供回调；目录中的零长度名称可能需要文件名回退上下文。缺失或损坏目录的模型头重建、运行时目录刷新、版本 5 非空扩展的映射，以及目录位图和部分头字段的业务含义尚未完成。目录匹配结果不替代目标文件定位和模型加载。

`BsplineCurve::native_derivatives_at()` 已提供原生曲线位置与导数约定，支持源节点参数导数、周期归约、有理高阶导数和特殊接缝检查。它遵循原生节点容差，不能保证所有结构有效的源曲线均可求导；零控制权重、分母奇点、数值溢出及超出曲线阶数 26／导数阶数 24 的请求会失败。其双精度递推在高阶、密集节点及导数接近零时可能放大舍入误差，不提供统一的导数误差界。`native_frame_at()` 已提供单条 B 样条的 Frenet／控制多边形／参考轴回退规则，原生零切线可能得到退化矩阵，调用方须检查 `basis_status`。

`native_curve_frame()` 已提供 CurveVector 的首尾、局部导数、跨子项和嵌套数组参考系选择，支持线段、点列、椭圆弧、B 样条及已支持的 Akima、InterpolationCurve、TransitionSpiral 转换路径。未支持的参数曲线片段或其他图元只有在查询实际需要它们时才返回 `not_evaluated`，不当作空项略过。已确认的原生节点容差失败可继续查找其他子项；零权重求导或非有限计算等限制不冒充原生失败返回。源空子项在普通遍历中可跳过，但原生后续导数配对没有空指针分支，库对此返回未求值状态。输入嵌套深度最多 80；成功矩阵仍可能退化，且不保证跨编译器浮点结果逐位一致。自动材质投影上下文、投影范围和最终 UV 映射仍未全部支持。

参数化构件中的 BGFB 已按 P3D 原生类型 20、21 读取路径扫掠与导引放样，包含省略的默认封口标志及嵌套导引组。类型 3、14 的源 B 样条曲线和底层曲面可通过 `BsplineCurve`、`BsplineSurface` 求值，支持开放、周期、非均匀节点和有理权重；这些接口不自动替代场景图形缓存。B 样条曲面提供独立的 UV 裁剪区域查询及下述范围内的派生网格；原生裁剪采样、布尔操作数和其他参数化变体的完整求值仍未全部支持。图形封装及条目已区分各自的样式、内嵌材质、图层和变换，条目按原生 64 位长度划界；未知编码仍保留原始字节。条目局部序号与所属实体重建后的材质部件编号尚未自动关联，额外版本字段仍可能报告未知后缀。

CSG 命令 58 和图形条目类型 10 已解码几何列表、缓存、变换、已知版本二叉树及嵌套 CSG 载荷，保留原生索引及未知载荷。节点和根网格输入接口已提供更新前的缓存／几何选择、首矩阵索引和单位矩阵回退规则；解码入口本身不执行布尔更新、结果生成或缓存有效性判断，专业附加数据语义尚未完全确认。下述求值接口提供各自限定范围内的派生结果。不能把操作数直接当作结果几何，也不能仅凭 `is_old` 标志判断结果正确。节点版本或内部几何不支持时，外层载荷仍可能成功读取，须检查各内部状态。`decode_csg_bytes()` 不调用厂商运行时服务；成功展开载荷不保证原生对象恢复成功。

独立的 `evaluate_csg_mesh_boolean()` 可对两个已构造的封闭三角网格执行并、交、差，并提供输出面来源及角点重心权重。它不自动恢复整棵原生 CSG，不证明与 BIMBase 内核的拓扑划分、容差处理或退化输入行为一致。派生结果可能因内核容差改变微小特征；源几何仍保持不变。输出面来源用于追溯属性，不能替代尚未完成的原生部件材质绑定。

`evaluate_csg_mesh_lists()` 和 `reduce_csg_mesh_list()` 已提供两组操作数及叶子单列表的运算分组、顺序和最初源面追溯。列表交集按对象逐对输出，不能把重叠组自动合并；空计算结果保留为空组，不能当作原生缓存序号。实际布尔运算要求封闭网格；不需要布尔运算的直接传递或空结果分支允许开放网格，仍验证坐标、索引、非网格内容和资源上限。它们使用同一独立网格内核，遇到失败清空结果，不模拟厂商内核错误后的继续处理。完整树更新、节点变换的原生对象作用域及实体离散化仍须另外处理。

`evaluate_csg_polyface_tree()` 已执行多面体树的节点更新、缓存重建、Compound 索引收集以及共享对象的累计变换。低层接口接收已三角化的 Polyface，`evaluate_csg_polyface_archive()` 可以从 BGFB 自动准备这些源网格，并按原生访问顺序变换、更新和展开嵌套 CSG。自动入口支持索引面、隐式三角形／四边形列表、行列网格及下述范围内的 DgnBox、DgnCone、DgnSphere、DgnTorusPipe、DgnExtrusion、DgnRuledSweep、DgnRotationalSweep 和 P3DSectionLoft 实体，尚不支持其余实体的离散化；嵌套的原几何或需先变换的旧缓存含有未支持实体时，也会明确失败。行列网格按原生直接遍历规则读取；每行点数不足 2 或末行导致缺角点时明确失败。输出及缓存采用派生内核，原生退化处理、空体缓存数量和最终材质绑定不构成等价保证；最终几何映射奇异或数值不可用时停止求值。源属性池通过源路径、源面、角点权重和累计矩阵追溯，不会自动转换为结果的全部属性通道。

`mesh_bgfb_solid()` 支持非退化的 DgnBox，包括倾斜箱体、四棱台及无封口侧面。底部和顶部的对应宽度必须非零且同号；塌缩、反向穿越及退化坐标框架明确报告未支持。返回的是原生角点和面轮廓的派生三角化，不保证原生网格细分、焊接顺序、法线、UV 或边可见性等价。原生实体面编号保留为 `face_indices`，不能直接当作材质部件编号。CSG 中每次实体转换生成独立网格，区别于多面体原对象共享；原始实体参数和派生网格分别保留。

统一实体入口也支持 `P3DSectionLoft`，沿用 `SectionLoft::mesh()` 的源曲线、分母、边界衔接及端盖平面要求，采样参数为 `max_uv_edge = 1 / circle_segments`。侧面曲面参数通过 `surface_parameters` 按输出三角形和角点保存，盖面为 null；它们不是材质贴图 UV。原生面编号无法确定时，统一入口明确失败。放样重建沿用独立接口默认控制点和工作预算，输出仍受统一入口的点、角点和三角形预算约束。CSG 在每次转换时先变换源截面和导引，再重建网格；重复引用保留逐次参数更新和各次独立网格。放样已转换成的派生多面体缓存仍按多面体处理。

独立的 `transform_bgfb_section_loft()` 已支持源截面和导引组中的线段、折线、B 样条、椭圆弧及嵌套曲线数组。按齐次坐标处理有理控制点，包括零权重点的平移；不修改权重、节点或源成员顺序。B 样条遵循原生近单位矩阵跳过规则：线性部分每项与单位矩阵的差不超过 `1e-12`，且每项平移严格位于 `(-1e-10,1e-10)`；线段和折线不套用这一跳过规则。椭圆轴长小于 `1e-5` 时按原生规则替换为极值线段：优先检查第一轴，舍弃它并使用第二轴上的 sin 极值；否则舍弃第二轴并使用第一轴上的 cos 极值。两轴都短时仍走第一分支，两轴都为零时保留退化线段。端点按标量最小值、最大值排列，不保证保持原弧方向；单位变换也可能触发替换。其他曲线类型、溢出、损坏输入和超出预算明确失败，且不返回部分参数表。奇异仿射变换可以完成源坐标运算，但后续曲面重建或网格可能失败；原生面身份与旧侧面之间也不能只靠一个累计矩阵追溯。CSG 已接通上述源变换和椭圆替换，重建后仍须满足对应网格接口的条件。

该接口也支持非退化 DgnCone 的均匀角分段网格，包括圆台、圆柱、单端尖顶和无封口侧面；两个半径均零或非零异号时明确失败。分段数由调用方选择，不保证厂商采样等价；源坐标弦误差上界不包含后续变换及布尔误差。原生放置会归一化两个截面方向，并只用第一方向的长度同时缩放两个半径，不能一律用输入矩阵直接变换圆锥顶点。`transform_bgfb_cone()` 和 CSG 自动入口已执行此规则；源追溯矩阵保存实际几何映射。原生角采样、法线／UV、边可见性和最终材质绑定仍未复现。

DgnSphere 支持非退化仿射球体／椭球体、正反纬度扫掠、截取球带与可选封口，原始两端纬度须位于 `[-π/2,π/2]` 且不同。奇异框架、零扫掠、越过极点或多周覆盖不生成网格，也不会悄悄限幅修正。均匀角分段使用调用方配置，误差界不包含浮点舍入及后续运算，不声明原生自适应细分等价。端盖按原生纬度容差选择；参数查询的 `native_is_closed_solid` 是标志及容差判断，不能替代网格拓扑检查。`native_bgfb_sphere_parameters()` 的扫掠查询会限幅，但源角度不变；查询成功也不代表可以生成几何。网格法线／UV、边后处理和最终材质绑定仍未复现。

DgnTorusPipe 已接入实体网格与 CSG，按原生路径旋转起始截面，保留原参数、面编号与有效变换。大半径绝对值必须严格大于非零小半径绝对值；尖触、自交环面、零扫掠、平行或无效方向不生成网格。扫掠生成按原生规则限制为一圈，原始多圈角度不删除。原生整圈容差判断、保存的盖面枚举和实际盖面生成分别提供；接近整圈的源端点不自动焊接，因此闭合标志不能保证派生结果封闭。放置会归一化方向、同时缩放两半径并重建法向，不等同于普通仿射变换。固定角采样没有复现原生自适应离散、UV、法线及边后处理，仍须分别判断这些属性和最终材质关联。

`DgnRotationalSweep` 的直接网格与 CSG 入口沿源轴线旋转已支持的截面，支持开放链、闭环、奇偶多环和独立联合子项。支持非零、绝对值不超过一周的正反扫角；零轴、零扫角、多周及无法处理的退化截面明确失败。原生端盖条件为源 `capped` 且扫角绝对值不大于 `6.283185307178586`；只有精确一周才连接派生网格的旋转接缝，因此近一周可能没有端盖但仍保留开口。精确落在轴上的采样点保持静止，其旋转产生的零面积索引三角形省略并计数；所有角向行索引仍受 `max_corners` 总预算约束。非退化侧面保留 `(0, flat曲线编号, 组件编号)`，端盖保留 `(-1,0/1,0)`。CSG 放置先判断变换坐标系的方向，镜像时反转扫角，再变换轴线和源截面并重建；非均匀缩放一般不等于对旧旋转体做仿射变换。方向判断所用的列向量叉积或第三列长度为零、长度运算溢出时不支持。源 `numVRules` 保留，但派生网格使用调用方的分段数，不复刻原生绘制线/采样设置，也不提供最终材质 UV 或空间自交证明。

DgnExtrusion、DgnRuledSweep 及上述旋转扫掠的截面支持线段、折线、椭圆弧及连续 B 样条，保留原曲线和内部段的原生面编号。B 样条支持阶数 2 至 26、非归一化节点域及周期表示；每条曲线仍对应一个原生组件，采样跨节点区间不会增加组件编号。对应截面使用相同的比例参数，派生采样纳入每个截面的节点位置；源节点、权重和参数对应不改写。正、负、零及混合符号控制权重可以保留，但必须先证明整段分母非零；真实奇点、数值不确定或预算不足明确失败，不以原生点求值的零分母回退掩盖曲线奇点。内部全重不连续节点目前不支持，也不会跨断点补侧面。

不同类型或内部段数不一致的对应曲线、零拉伸、退化侧片、投影后相交而需要新增边界点的封口，以及上述范围外的曲线目前不支持。非平面封口通过工作副本的正交投影确定连接，输出仍保留原三维边界点；投影方式和三角化对角线不保证与厂商等价，不能据此声称恢复了唯一的非平面解析曲面。相邻曲线只接受浮点舍入量级的端点差，不补缺边；奇偶区域的子项须是闭合环，暂不支持其中继续嵌套区域。联合区域子项分别构面，不额外布尔合并。角采样、B 样条比例采样与非平面侧片分带为派生算法，尚无三维误差界，也不保证原生采样、接缝焊接、法线、UV、边标志、最终材质或自交处理等价。上述扫掠封口处理不改变导引放样的独立平面校验要求。

`mesh_bgfb_polyface()` 的几何成功状态与属性绑定状态相互独立。缺失或空法线／UV 索引仅在其完整元素数等于完整点数时，按原生规则回退到点索引；不同颜色池分别验证，不应用这条回退，也不以较长的池掩盖较短池的越界。原始表、未用点、标量尾部及额外字段仍保留。派生边界可消去相邻零长度边及三维精确共线的折返；仅在投影中精确折返而三维不共线时，保留对应三角面及原角点来源。整理不改写原点池，不焊接独立源顶点，也不按近共线容差删除微小特征。整理后仍自交／接触、全部退化、索引未终止或超出资源预算时不输出部分网格。此整理及三角剖分不承诺与厂商的容差、拓扑和排序一致；生成网格不等于已证明三维无自交、闭合或满足布尔内核要求。原始边可见性独立保留，新增或短接边没有完整原边对应时不猜可见性，也不据此判断最终视图显示。

`BsplineSurface::trim()` 支持线段、折线、圆弧、B 样条、Akima、InterpolationCurve 和 TransitionSpiral 边界，以及区域树中的环收集与奇偶填充。环内直接出现的 CurveVector、PointString 按原生转换失败规则记入 `ignored`，不自行展开或连线；原树中的端点仍参与 Open 的闭合检查。其他未支持的边界类型会明确报告。内部零权重或混合符号权重可经齐次细分继续求值；端点零权重、实际分母奇点和大于浮点余量的内部连接间隙仍可能使转换失败，不自动拟合或连接内部间隙。已接收的 Outer/Inner 连续链按最后一点到第一点的直线边闭合；报告保留该派生边，源曲线不改写。达到线段预算、细分深度或浮点精度限制时报告 `incomplete`，查询返回 `Indeterminate`。派生折线及其偏差界不等于原生采样结果，不包含曲面三维误差约束；缓和曲线的偏差界针对拟合 B 样条，不包含其与底层积分曲线的差异。末尾闭合边不做最短跨缝解释，三维端点重合也不自动生成周期带状区域。调用方必须处理边界带和不确定状态。

`BsplineSurface::mesh()` 提供带孔、奇偶区域裁剪及单位参数域求交后的派生三角网格；它不复刻原生缓存的采样或三角形顺序。开放、单向周期和双向周期裁剪曲面支持非归一化节点域，先将边界齐次控制点映射为曲面比例参数，再按该坐标系中的容差离散；源数据保持不变。周期方向不改变保存的 UV 闭合区域：域外部分被裁切，不自动平移复制到对侧，接缝保留独立 UV 顶点。内部全重节点按断裂分片，保留单侧值和独立边界顶点，不根据位置相同而自动焊接。内部节点重数超过阶数、不同断裂归一化后无法区分仍不支持。零或混合符号的曲面权重通过逐节点矩形的 Bernstein 区间细分确认分母非零后，可继续网格化；不是只检查网格采样点。真实分母零点、区间精度或工作预算不足仍返回未完成。当前分母判定覆盖整个有效参数域，即使奇点位于被裁剪掉的区域，也不会跳过；这与裁剪边界曲线的权重限制是不同环节。精度选项约束 UV 边界近似和三角形边长，不提供三维弦误差界。数值无法可靠求交、细分精度不足或预算耗尽时返回 `incomplete` 和空几何，不以部分网格表示完整曲面。此接口不提供封口、材质部件映射或自动场景替换。

Akima 转换遵循原生 6 至 5000 点及过滤后至少 6 点的要求，首尾各两个保留点用作切线支持。转换错误由 `_akima.status: invalid` 或 C++ 异常表达，源点仍保留。非有限坐标、距离或参数范围溢出明确拒绝；不补造辅助点，不将无效插值输入退化为折线。派生 B 样条与活动场景、导引曲面和布尔操作之间的完整求值关联尚未全部接通。

`InterpolationCurve` 采用 BGFB 原生读取路径的固定三次转换，保留但不使用源阶数、节点和端部切线，不能用作接受任意阶数或显式端部切线的通用插值器。过滤与闭合准备后最多 4998 点，闭合标志可按原生退化规则转为开放表示。失败通过 `_interpolation.status: invalid` 或 C++ 异常表达；不以折线代替失败的插值曲线。该接口与其他参数化操作及活动场景的完整求值关联仍受上述限制。

`TransitionSpiral` 支持原生工厂类型 10 至 14 的底层求值及 `native_fit()` 拟合 B 样条转换，拟合结果也用于曲面裁剪边界。底层积分的误差界不含浮点舍入；拟合器的收敛条件只衡量弧长参数变化，不提供底层曲线与拟合结果的几何误差界。`native_fit_input()` 的积分误差值同样只是原生估计。库保留短点列的原生边界方程和反向区间的半径符号规则；不能把拟合参数直接代入底层求值，也不能假定反向拟合等于正向控制点倒序。超出数量/积分预算、退化参数、数值溢出或 30 次内未收敛时抛出异常。活动场景的完整求值关联仍未提供。未知类型、无法确定长度或不满足原生曲率/方位角条件的数据保留源字段，并在 `_spiral` 中报告错误。

`SectionLoft` 提供 BGFB 源放样的 B 样条侧面；`cap_regions()` 可按原生端部提取、闭合检查和方向规则构造底、顶封口边界区域，`mesh()` 可对已支持侧面及平面封口生成连接网格。封口区域成功不保证内部边界连续、共面或实体有效，不自动补线或投影。网格接口目前不支持非平面盖面、需要新增交点的自交/接触裁剪环及退化三角形；无法保留盖面全部边界采样时明确失败。精度选项约束侧面 UV 边长，不提供三维弦误差界；只报告索引边连接和方向，尚未检测整个实体的空间自交或顶点流形性。原生 Open 的独立首末导引不自动焊接，中间可能仍有开放边。其 B 样条边界支持开放夹持、普通周期和特殊闭合节点表示，支持非零的正、负或混合符号控制权重及连续内部节点，支持次数 1 至 25。按控制多边形长度连接后的闭合导引支持原生关闭及重新打开，包括普通周期转换、特殊直接打开和端点检查失败后的循环回退。周期打开请求节点参数零；源有效节点区间不包含零时失败。支持按原生容差吸附到接缝附近的已有节点；多个不同节点被判入同一容差组、导致打开结果仍非夹持的情况尚未接入侧面构造。某些重复接缝位于节点域末端的非归一化表示也仍未支持，不进行越界控制点复制。开放非夹持、内部全重不连续、源零控制权重、联合区域及嵌套导引尚未支持；升阶、节点兼容或关闭转换生成零中间权重时同样可能失败。侧面构造产生的零权重按原生乘积规则保留，构造成功不保证曲面处处可求值。网格生成前逐侧面验证整个参数域的有理分母非零，遇到奇点、数值不确定或验证预算耗尽返回未完成和空几何。封口网格支持混合符号的有理边界，按实际节点区间验证分母非零及整条曲线到平面的距离上界。验证不能完成时返回未完成，不以控制点或采样点共面代替证明；侧面构造产生的零权重端部控制点可保留在封口区域中，并参与完整分母及平面界验证；端点采用原生曲线求值的零权重回退规则，因此区域闭合成功仍不保证分母非零。零权重边界的原生封口 UV 查询仍受其参考系及范围求值限制。极端尺度、节点聚合和浮点精度不足可能使构造失败。Akima、InterpolationCurve、TransitionSpiral 在这条原生放样转换路径中不返回 B 样条对象，因此明确拒绝，不能自动用裁剪路径的拟合缓存替代。源表仍可通过底层接口完整读取。命令流放样的网格支持范围与此显式参数曲面接口分别说明。

变电站 `ElecParaData` 支持外层版本 0、1 和 `PBWJData` 版本 0 至 2，包含非空截面、柱参数、桁架梁及人字柱集合。`SubsColPar` 支持版本 0 至 6，`TrussBeam` 支持版本 0 至 5，`HumanColumn` 支持版本 0 至 4；嵌套的 `TrussBeamPar` 支持版本 0 至 3，其中版本 2 不保存成员载荷，返回空 `members` 和 `member_payload_status: not_serialized`，不补运行时默认值。遇到未支持版本或损坏的内部长度时，保留完整原始载荷并报告字段解码错误。

原生可见性与视图规则尚未完整支持。历史缓存记录保留在底层接口中，不额外加入活动场景；活动场景不保证与原软件某个特定视图的显示列表完全相同。

支持的图形记录通过构件 `metadata.display_state` 提供永久隐藏标志。此标志不等同于视图可见性；图层、模型链接、裁剪和临时显示状态仍需结合各自的数据。未支持的头布局明确标记 `unsupported_header`，不会从任意记录的同一偏移猜测显示状态。

图层组合的覆盖位图及同步模式已通过底层属性接口展开。`layer_tables().group_states` 可按模式及覆盖位计算颜色、线型、线宽、显示、打印、冻结和透明度，并提供每项原生来源；同步中的成员增删也已表达。名称表更新、其他样式、模型链接继承及视图条件尚未全部合并，因此此结果不等同于最终视图可见性。

图层独立记录的版本 1 至 7 可读取名称、描述、显示、打印、冻结、访问模式、颜色索引、线型、线宽和透明度；版本 4 至 7 还提供业务代码。其他版本明确标记未支持。图层表成员、覆盖属性来源和模型到组合表的 ID 引用可通过 `layer_tables()` 读取；尚未确认的字段继续保留，链接路径的完整运行时解析及最终继承结果仍未求值。

命令流中的图层 ID、样式继承标志及填充样式块可读取，但尚未完整计算图层继承和最终显示样式。涉及未支持继承条件、渐变填充或显示上下文时，外观摘要的 `color.rgb` 返回 null，`color.source` 说明原因。线型修饰参数及复合绘制状态的存储布局已展开，部分字段和功能码仍未确认含义。

## 几何与坐标

`p3d/pcurve.hpp` 提供显式曲面与参数曲线的原生采样接口，支持二阶控制点线段及高阶有理曲线的采样、起点省略和细分停止规则。`sample_native_pcurve_loops()` 提供已转换、打开且 UV 已归一化的边界环采样，包括范围容差选择和环内流状态。`sample_native_surface_boundaries()` 已接入曲面的源区域树、原生成员转换、周期打开和源 UV 映射；周期打开支持负权重及内部全重节点；特殊接缝直接打开可保留零权重，普通分支的权重还原仍拒绝零权重与非有限计算。源节点域必须包含请求的零，退化节点区间、未满足循环插入前提的布局及预算不足仍返回未完成；打开成功不表示断裂或数学奇点已消失。首次原始 UV 缓存通过独立入口 `sample_native_initial_surface_boundaries()` 重建，保持源节点和边界坐标，仍遵循原生线性 UV 夹持及曲面点内核的上界 1 规则。非单位节点域下的中间位置不等于数学曲面求值；无效原生节点窗口明确失败，不自动归一化替代。网格阶段闭合、三角化及场景网格衔接仍未全部接通，这些采样入口不等于完整原生裁剪流水线。点求值已使用该原生调用链的参数夹持、节点区间选择、闭合控制点索引及基函数计算顺序，支持不超过 26 阶的曲线和曲面。域外高阶 UV 保留在返回参数中，曲面位置按夹持参数求值。参数曲线的零分母回退单独记录，不代表数学奇点消失；曲面零分母、非有限求值和库预算不足仍返回未完成。原生三点误差及细分上限不是连续误差保证，也不保证与厂商浮点运算逐位一致。

文字图形条目和命令 37 已共用文字封装读取，版本 1 的附加样式提供上下划线和背景参数、字间距模式及使用条件、行偏移、大字体编号、自定义斜角与已确认标志。线型另提供有符号解释；源颜色、距离及线宽不自动转换为最终外观。部分附加字段、未命名模式及字符位图的业务用途仍未确认；字体解析、排版与字形轮廓不由这些源字段自动生成。未知版本或损坏的附加头不会被当成完整样式。

原生类型 54 的文字已区分二维与三维布局，并提供字体引用、原比例、原生字体大小、存储宽高及文字后的区间。字体声明目录可在文件系统列表首次输入的限定范围内选择字体表、处理重号并查询主字体请求；在调用方提供字体资源状态后，可进一步求值主字体替换、大字体选择及主字体为大字体时的调整；资源发现、实际字体加载和后续宿主回调尚未自动执行。`map_native_text_characters()` 可根据显式上下文执行 TrueType、Unicode SHX 和传统 SHX 的字符映射；传统 SHX 所需的符号配置、代码页和解码器由调用方提供，库不会按字体名称或操作系统区域猜测。`fffd` 的原 `text` 仍只是 GB18030 兼容预览，完整码元和原字节均保留。原生文字的三类样式链接已接通读取、首项选择和控制位覆盖，部分控制字及辅助参数用途仍未确认；文字区间、字形轮廓和完整排版规则尚未全部求值，不能仅因文字读取或字符映射成功就认为排版和字形已经恢复。

- 曲线和曲面重建涉及采样。默认整圆 64 段；弦高使用源坐标单位，实例缩放不会自动触发共享定义重新采样。
- 非单位地形变换及未支持的导引曲面变体会报告未知项，不能视为已经成功生成几何。导引放样支持两个闭合截面，保留外环、内环和源导引组的顺序对应，也支持无内环的两个开放截面；支持折线、圆弧、椭圆弧、一周周期圆锥曲线及由这些命令组成的连续导引。开放路径类型不排除封口，但上下封口边界必须分别通过原生首尾重合检查，且可按平面多边形三角化；真正开放的端面不会自动补边。将任意周期 B 样条用于导引曲面重建，以及多周圆弧、嵌套复合导引、联合区域，尚未支持。
- 导引曲面的边界按源顺序固定对应，不自动重排或翻转错序导引。角点按各坐标分量的 `1e-5` 阈值检查；复合导引接缝及闭合检查使用各自的原生容差，详见格式说明。不连续复合导引仍未支持。折线保留输入转折点，尚未完整重现原生曲线拟合及节点合并的容差处理；弦高约束针对本库构建的曲面侧面，不表示与原软件的网格逐点相同，也不包含封口面误差。
- 源三角形包括退化三角形，库不会自动简化或合并独立几何。
- 显式多边形网格的法线、UV 及独立角点索引由 `Geometry` 提供，缺失时不生成或借用顶点索引。法线变换不自动单位化；奇异或不可表示的结果为空，原始法线仍保留。颜色、名称、附加逐面 UV、平滑组和材质列表由 `mesh_channels` 提供；固定宽度面的逐面组合要求零分隔读取结果与源面吻合，数量不匹配时不猜对应。`mesh_material_references` 解析逐面材质列表中的定义候选，尚不计算它与范围或部件样式的最终覆盖。`native_triangulation` 已表达一条原生路径的 UV 选择、材质复制/补零和法线分组规则。满足条件时另提供对库现有三角形计算的派生角点法线；`triangulate_native_mesh()` 另提供原生 GLU 三角化及后续位置、UV、法线注册和单精度索引网格导出，区分平滑与非平滑分支的原生复用；其他渲染路径及最终外观继承仍未完成。附加 UV 和派生法线不自动替换源池。六组通道之后的额外字节仍报告未知后缀。
- 坐标、单位与模型信息按源数据提供，不自动推定 CRS。跨坐标系处理前，需要调用方确认单位、轴向与定位信息。

## 材质与外部资源

`parametric_append_input` 已确认部分几何类型在参数化缓存合并中的复制与单次追加条件，包括递归曲线组、拉伸、扫掠和导引放样。它假定源容器及原始条目几何已恢复、目标容器未完成且未启用变换，并假定分配成功、服务正常返回；不自动确认缓存回退是否被选中或源容器后处理是否改变了输入。`appended` 不是最终材质部件绑定完成的标志。源几何可以读取但不能安全复制时，仍返回未求值，不擅自丢弃该条目并压紧后续编号。

图形缓存的 `native_geometry_input` 可确认部分原生拒绝条件、读取分支，以及基础实体、多面体、部分曲线、曲线组、拉伸、多截面扫掠和导引放样的几何构造条件。曲线组、截面和导引递归依赖已支持的子类型；其中未支持的已知类型不会按空对象跳过。`geometry_constructed` 只表示成功分配时可以形成非空几何对象，不保证几何有效。各上下文中的 `entry_restore` 可继续判断条目读取器在尾部处理后是否返回非空条目，但假定有效模型、成功分配和服务正常返回，不包含容器 `finish()`、后续几何复制及最终追加。内嵌材质构造后的当前项目注册、名称查询和覆盖仍未自动求值，源参数不等于最终生效参数。`parametric_append_rule` 提供参数化追加时的属性传递和跳过规则。这些结果不能单独确定最终部件编号。被原生读取器拒绝的容器仍保留可检查的原始条目；不能把这些条目作为有效容器继续推导材质编号。

`resolve_rebuilt_graphics_materials()` 已提供显式重建条目顺序下的部件／实体／条目材质选择，包含原生重复属性选择、名称边界和未知状态传播。名称查询及条目材质转换需要调用方提供真实加载结果；目录中存在同名记录不代表加载成功。它不自动恢复参数化组件重建前后的条目关联、不计算三角形对应，也不改写场景缓存已有样式。接口要求完整选定属性集合及有效的普通绘图上下文；样式对象内嵌于上下文，不是逐条目可选的构建器。结果仅到样式求值前的材质选择：`unassigned` 表示这一步写入空材质，后续原生样式求值仍可能查询材质，不能据此断定最终绘制没有材质。`draw_material_status` 明确为 `not_evaluated`。高级正向表支持 JSON 行注释和块注释，以及字符串、64 位整数、布尔值和空值的名称转换；浮点值、数组／对象名称及其他未支持的语法仍返回未确定状态。

`lookup_native_material_name()` 已提供准备完成目录中的全部同名候选收集、顺序加载及首个成功结果选择，保留重复结果。名称比较所需的来源区域设置与候选的实际加载结果由回调提供；项目选择、目录更新、跨项目缓存复制和资源提供者尚未自动接通。查询成功不等于整个材质绑定链已经完成。

`resolve_native_entity_material()` 已从实体源链接接通首项 ID／名称选择、主查询与外层 ID 回退，并可把结果交给重建图形材质选择器。它仍要求明确的所属项目、实体模型资源可用状态及真实查询／加载回调；这些运行时关系尚未全部由文件自动恢复。不同 ID 查询的资源上下文和更新参数不能合并，缺失上下文或未知加载结果不会作为未命中处理。该接口不自动恢复部件与三角形关系，也不加载贴图。

图层／颜色材质分配表已支持 XML 源规则、原生插入时的颜色合并／扣除、精确和模式两轮查询、已选模型头属性中的按名选表，以及已准备目录中的 ID／名称加载顺序。不同名称的忽略大小写比较、模式中的大小写转换需要匹配来源运行时的区域设置；扩展颜色需要已选模型的颜色表。DTD、带命名空间的表、过深的 XML、不完整 RGB 转换和会越过名称终止符的原生模式分支保留为未确定状态；选表遇到无法确认的前项会停止，不猜测厂商解析器是否跳过该项。实际模型选择、版本化模型设置中的表名恢复、父级资源查找、目录更新、运行时缓存及提供者加载仍需对应上下文，不能把分配规则命中等同于最终绘制材质。

`paletteList` 的材质库引用已提供源项和原生前缀／名称拆分，实际资源提供者的查找、加载及注册后的去重集合尚未求值。重复源引用保留，不用路径归一化代替原生资源身份比较，也不自行定位外部材质库文件。

`lookup_native_material_id()` 已从已准备的注册目录确定 ID 与资源索引键对应的唯一条目，保留原条目索引并执行单次加载。项目选择、需要时的目录更新、资源键获取及真实缓存／提供者加载仍需接入；不能把初次注册目录视为所有后续时刻的完整目录。符号当前上下文仅在同一目录内有效，跨上下文关系不明确时返回未确定。不同具体键的比较须与来源区域设置和目录注册一致，不默认用路径归一化或 ASCII 大小写转换代替。

`native_input_containers()` 已提供系统初次输入时的材质表选择及接受成员，包含重复 ID 分配和输入序号。它要求可确定的普通文件头、列表准备及系统 ID 分配；追加到已有宿主对象、后续模型操作和外部资源上下文的活动表不由该接口求值。

## 错误与歧义

视图链接顺序可在明确的原生链接列表和候选上下文下协调、构造默认值并排序；候选收集可沿已提供对象图的父链接链筛选归属。普通加载入口的链接排序及“先协调、再排序、必要时构造默认顺序”已支持，保留原生相等项排列与重复来源。模型自动选择、运行时对象图的自动构建、链接列表的外层加载、图层和显示样式叠加、完整裁剪与最终可见性尚未全部接通。顺序接口的 `resolved` 或 `ordered` 不表示完整视图已重建。

引用祖先重复判断已支持显式加载上下文中的原生条件与层级阈值，但全局设置、文件提供者状态及宿主链尚未自动恢复。宿主排除筛选、普通加载状态决策及活动／副列表插入规则也可在明确上下文下求值；后代门控及按原生顺序搜索已提供的活动引用图也已支持，区分对象身份、虚拟类别和独立运行时标志。已确认普通模型／引用实现及父关系时，可自动推导后代搜索门控和所属模型起点，但完整图仍需调用方提供。输入回调及从文档构造完整引用图尚未自动接通，不能把 `repeated: false` 或原生返回码零当作引用已经成功加载。列表判断保持原生区别：活动列表不去重，副列表只按次级键阻止重复追加。

已支持从类型 13 记录恢复普通输入成功后的初始运行时控制字，并在明确的文件规格下构造搜索查询；它不能替代外层加载、服务处理或回调已经改变的对象状态。引用掩码记录的首项选择和四个存储字已提供，细分用途及最终视图应用仍未全部确定。

普通初次输入的主、次标志已接通矩阵缩放重算、控制依赖首项选择和裁剪深度检查，并可用于记录驱动的加载决策。控制依赖编号保留为原生 64 位引用，不表示其目标对象已找到；外层加载和回调后的标志仍需实际上下文。

引用嵌套深度已关联到源字段，可沿明确父链计算剩余深度和位 14 输入限制，并判断该轮是否处理视图顺序。新建普通引用节点可从记录初始化，但该节点尚未连接目标根模型或加载自身活动链接；此接口不等于已自动恢复最终跨文件引用图。

单条引用请求已支持登记表门控、活动/副列表按实际输入编号返回已有对象。它要求调用方提供当前完整登记表及所访问的对象图，保留原生身份和顺序；不能由初次登记表推断全部后续加载状态，也不替代批量收集或目标连接。

文件取得后的目标模型选择和缓存查询已接通，支持默认模型优先级、显式编号、名称目录顺序、有符号编号守卫及专用模型槽。模型构造、资源提供者刷新、实际挂接及后续内容加载尚未自动执行；提供者的中间对象不能代替完整构造结果，`matched` 也不表示已完成这些后续步骤。

对象图可通过明确连接身份共享目标模型信息，根查询和后代匹配已接通；反向引用列表的直接增删规则也已提供。实际连接身份仍需可靠来源，列表操作不包含挂接/解绑时的通知、子引用清理及其他回调效果，完整自动挂接过程尚未完成。

文件加载失败可能抛出异常；部分字段或几何失败则保存在结果中。调用方应同时检查：

- 记录或字段中的 `decode_error`、`parse_error`、`field_decode_error`、`topology_decode_error` 等诊断信息。
- 场景元数据中的 `errors`、`library_errors`，构件与定义中的 `unknown`、`notes`。
- 对象、绑定、层级边、块引用和材质的 `missing`、`ambiguous` 等状态。

CLI 退出码为 0 表示执行完成，不表示所有字段都已被理解。某项数据保留了原始字节，也不意味着它已被转换为可直接使用的几何或语义对象。

## 数值与接口

标准 JSON 文本不能原样表示 NaN / Infinity，导出时写为 null；原始字节仍保留，C++ 内存中的浮点值不因此改变。超过 2^53 的整数应使用能够无损表示它们的目标类型，避免通过 JavaScript Number 往返。

对象 ID、模型 ID、定义索引和 `source_key` 均属于当前文档。组合多个文件时，需要增加调用方自己的文档身份。

当前 `0.x` 接口尚未承诺稳定 ABI；静态库应使用兼容工具链构建和链接。

模型边线缓存已支持属性索引选择、版本 51 的压缩模型分块、子模型树、字符串登记表、图形区段和代理实体中的已有格式命令；可选模型头已接入单位、坐标和已有视图标志解码，引用参数已提取保存的标志、矩阵、比例及点。最终引用连接及显示规则尚未接通；模型头和引用参数中的其他字段、组件字段、可选 96 字节块、显示头及线型修饰仍按源载荷或来源位置提供。参数解码不代表已对实际引用对象应用；结构读取状态也不保证命令层的每种几何都能重建。其他不低于 15 的缓存头版本仅读取公共头，不解释后续模型。

索引 65535 已支持引用目录路径、引用摘要、实体编号、最后修改时间和关联条目之间的源索引。已提供实体状态比较与原生关联集合选择查询，但实际对象匹配、当前摘要生成及显示回调尚未自动接通，需明确上下文才能求值；源索引存在不代表关联有效。修改时间采用 SDK 声明的本地时间基准，不能直接作为 UTC 时间戳。原生没有声明的实体合并或几何复用不会由库自行引入。

缓存状态摘要已支持字段解码和原生比较规则。尚未重建完整运行时摘要输入及所有缓存有效性条件，摘要匹配不代表缓存可用于当前场景。
